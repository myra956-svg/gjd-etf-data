## 一、东方财富（主数据源，免费、无需 token）

### 1. 实时批量行情

```
GET https://push2.eastmoney.com/api/qt/ulist.np/get
  ?secids=1.510300,1.510050,0.159915
  &fields=f2,f3,f4,f5,f6,f8,f10,f12,f13,f14,f15,f16,f17,f18
  &fltt=2
```

- `secids`：`1.` 前缀 = 上交所，`0.` 前缀 = 深交所，逗号拼接多只
- `fltt=2`：价格返回浮点（不传会返回整数，需 /100）
- 返回 `data.diff`（数组或按 code 索引的对象）

**字段映射**：

| 字段 | 含义 | 字段 | 含义 |
|---|---|---|---|
| f2 | 最新价 | f12 | 代码 |
| f3 | 涨跌幅 % | f13 | 市场（1沪/0深） |
| f4 | 涨跌额 | f14 | 名称 |
| f5 | 成交量（手） | f15 | 最高 |
| f6 | **成交额（元）** | f16 | 最低 |
| f8 | 换手率 % | f17 | 今开 |
| f10 | 量比 | f18 | 昨收 |

### 2. 指数行情

同 `ulist.np/get`，secid：`1.000001` 上证 / `0.399001` 深证 / `0.399006` 创业板 / `1.000688` 科创50。

### 3. 日 K 线（算 20 日均量 / 放量基准）

```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get
  ?secid=1.510300&klt=101&fqt=1&end=20500101&lmt=20
  &fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57
```

- `klt=101` 日K；`lmt=20` 近20日
- 每条 `日期,开,收,高,低,成交量,成交额` —— **索引5=成交量，索引6=成交额(元)**

### 4. 5 分钟 K 线（近 20 日分时 → 10分钟基准曲线）

```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get
  ?secid=1.510300&klt=5&fqt=1&end=20500101&lmt=960
  &fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57
```

- `klt=5` 5分钟K；`lmt=960` ≈ 20 个交易日（每日 48 根）
- 字段同上：**索引6 = 成交额(元)**
- 可聚合到 10 分钟（每 2 根 5 分钟线求和）或直接算累计

### 5. 分时（当日 / 近5日）

```
当日： GET https://push2.eastmoney.com/api/qt/stock/trends2/get
        ?secid=1.510300&ndays=1&iscr=0&fields2=f51,f52,f53,f54,f55,f56,f57,f58
近5日：GET https://push2his.eastmoney.com/api/qt/stock/trends2/get?ndays=5
```

- `ndays` 最大 5，只能拿最近 N 个交易日（不能指定历史区间）
- 每条 `日期 时间,开,收,高,低,量,额,均价` —— **索引6 = 成交额(元)**

### 6. 主力资金流（日度）

```
GET https://push2.eastmoney.com/api/qt/stock/fflow/kline/get
  ?secid=1.510300&klt=101&lmt=1&fields2=f51,f52,f53,f54,f55,f56
```

- 第 2 列（f52）= 主力净流入

### 7. 季度规模变动（JSONP 加载）

```
https://fund.eastmoney.com/pingzhongdata/{code}.js
```

- 用 `<script>` 标签加载，读全局变量 `Data_fluctuationScale` = `{categories, series:[{y:规模亿, mom:环比}]}`

## 一·补、新浪财经 + 腾讯行情（前端直连源，2026-11-24 实测入库）

> **角色定位**：本项目数据层服务于「ETF 资金流向分析助手」——监控 A股宽基 ETF 的**成交额**（新浪）与**净申购**（腾讯份额日度变动），两条数据源均免费稳定，可放心作为生产依赖。

### 1. 新浪 K 线（价格与成交额：盘中放量监控 / 日线汇总）

```
GET https://quotes.sina.cn/cn/api/jsonp_v2.php/{回调名}/CN_MarketDataService.getKLineData
    ?symbol=sh510300&scale=1|240&ma=no&datalen=N
```

- 回调名写在**路径段**（非 `cb=` 参数），如 `.../jsonp_v2.php/mycb123/...`，返回 `mycb([...])`，`<script>` 标签可直接加载
- `scale=1` 分钟线、`scale=240` 日线；`volume` 单位 = 股
- 成交额口径：`成交额 = volume × close`（估算，规范默认口径）
- ⚠️ **实测修正**：返回项其实带 `amount` 字段（真实成交额，元），**优先用 amount**；仅在缺失时才用 `volume × close` 估算
- ⚠️ 偶发返回前缀 `/*<script>location.href='//sina.com';*/`，不影响 JSONP 执行；偶发连接失败，需容错 + 超时
- symbol 前缀：`sh` / `sz`

### 2. 腾讯行情（份额 / 净资产）

```
GET https://qt.gtimg.cn/q=sh510300
```

- GBK 编码，`~` 分隔字段
- `[44]` = 净资产（亿元）、`[72]` = 份额（份）← **核心，净申购 = 今日[72] − 昨日[72]**
- **现价验算公式（实测修正量纲）**：`现价 = [44] × 1e8 ÷ [72]`（[44]亿元→元、[72]份；159915 实测 1268.09亿 / 539.15亿份 = 2.352 = 现价 ✓）。注意不是 `÷[72]×10000`——那是 [72] 以万份计时的量纲，腾讯返回的是份
- ✔ 交叉验证：`[72]` 已与集思录付费数据核对一致（用户确认），可放心用作申赎计算基准
- ⚠️ **实测修正（2026-11-24 09:50 盘中验证）**：`[72]` 是 **T-1 收盘确认份额**——盘中返回值与上一交易日收盘完全一致（510300 实测 555.8719 亿份），盘中不跳动。**不能用于盘中申赎实时监控**，只适合每日盘后确认 / 跨日对比

## 二、CORS 结论（最重要，务必记住）

东财 `push2` / `push2his` 系列接口 **不返回 `Access-Control-Allow-Origin` 头**。

- ❌ 浏览器跨域 `fetch` → 被 CORS 拦截
- ❌ JSONP（`cb=` 回调）→ 东财返回 `application/json` MIME，`<script>` 拒绝执行
- ❌ WorkBuddy 本地沙箱 / 云端 sandbox 服务器直连 → 东财断开连接（`Remote end closed`）
- ✅ **唯一可靠路径**：GitHub Actions 服务器端抓取 → 写入仓库 `data/` → 前端经 `raw.githubusercontent.com` 跨域读取（raw 返回 `Access-Control-Allow-Origin: *`，匿名可读）

> 教训：本地用 curl/python 验证"数据可达" ≠ 浏览器能直连。必须确认 CORS。

## 三、同花顺 iFinD / Wind（辅助，仅 WorkBuddy 会话内可用）

这两个是 WorkBuddy 的 MCP 工具，**无法放进 GitHub Actions 自动跑**（需要专属凭证），只能在 WorkBuddy 对话中调用，适合一次性拉取 / 生成数据。

### iFinD：`security_highfreq_quotes`

- `market=基金`，`data_mode=highfreq`，`interval=10`（10 分钟 bar，也支持 1/3/5/15/30/60）
- `symbols` 用 `.SH` / `.SZ` 后缀（如 `510300.SH`、`159915.SZ`），**一次最多 10 只**
- `indicators=成交额,开盘价,最高价,最低价`
- **仅支持当日日内，不支持历史**
- `data_mode=real_time` 可取最新价 / 涨跌幅 / 成交额

### Wind：`get_fund_kline` / `get_fund_quote`

- `get_fund_kline`：`period=4` = 10 分钟 K 线，支持 `begin_date`/`end_date` 查历史日，含 TURNOVER（成交额，元）
- `get_fund_quote`：分钟级价格序列（含成交额）
- windcode 格式：`588200.SH`

## 四、ETF 份额 / 期货（盘后，fetch_daily.py）

- **上交所份额**：`https://query.sse.com.cn/commonQuery.do`（`sqlId=COMMON_SSE_ZQPZ_ETFZL_XXPL_ETFGM_SEARCH_L` + `STAT_DATE`，Referer 需 `sse.com.cn`，支持历史日期）
- **深交所份额**：`https://fund.szse.cn/api/report/ShowReport`（`SHOWTYPE=xlsx CATALOGID=1000_lf`，仅当日快照）
- **中金所期货**：`http://www.cffex.com.cn/sj/ccpm/{YYYYMM}/{DD}/{IH|IF|IC|IM}_1.csv`（GBK，前 20 会员持仓）
- 估算净流入 = (当日份额 − 前日份额) × vwap

## 五、GitHub 中转架构（本项目核心）

```
东财/交易所公开接口
        │  (GitHub Actions 服务器端抓取，无 CORS 限制)
        ▼
GitHub 仓库 data/*.json  ──(自动提交)──►  raw.githubusercontent.com (CORS: *)
        │                                        │
        └────────────── 前端 fetch (跨域 OK) ◄────┘
```

- 前端单文件 `frontend/index.html`，经 `workbuddy_sites_deploy` 部署为在线链接
- 数据读取 URL 形如 `https://raw.githubusercontent.com/myra956-svg/gjd-etf-data/main/data/quotes.json?t=<时间戳>`（加 `?t=` 穿透缓存）
